Island Hopper is a 3D chase-view flight game: fly a little yellow plane over the procedural island of Kaluna, thread six glowing rings, watch your fuel, and land back on the runway before the clock runs out.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 in a desktop browser. No build step, no network — everything runs from the static files.
